This guide walks you through building a clean, production-ready plugin on Blank Board.

## Quick Summary of Plugin Rules
- **UI Root**: Render all UI inside `api.container`.
- **Drag & Resize**: Automatically provided by the core container.
- **CSS**: Inject styles using `api.injectCSS(css)` (automatically scoped to your container).
- **Storage**: Use `api.storage.get()` and `api.storage.set()` (automatically scoped to your plugin ID).
- **Timers**: Use `api.setInterval()` and `api.setTimeout()` (automatically cleared on unload).
- **Zero-Leak Cleanup**: The v5 core automatically cleans up event listeners, hooks, DOM elements, and timers!

## Step 1: Create the Plugin File

Create a standalone JavaScript ES Module (e.g. `counter-widget.js`):

```javascript
export const meta = {
  id: 'counter-widget',
  name: 'Quick Counter',
  version: '1.0.0'
};

export function setup(api) {
  // 1. Inject scoped styles
  api.injectCSS(`
    .counter-card {
      padding: 16px;
      display: flex;
      flex-direction: column;
      align-items: center;
      gap: 12px;
      font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
    }
    .counter-display {
      font-size: 32px;
      font-weight: 700;
      color: #7c6fff;
    }
    .counter-controls {
      display: flex;
      gap: 8px;
    }
    .counter-btn {
      background: #f0f2f5;
      border: 1px solid #dcdfe6;
      padding: 6px 14px;
      border-radius: 8px;
      font-weight: 600;
      cursor: pointer;
      transition: background 0.15s;
    }
    .counter-btn:hover {
      background: #e4e7ed;
    }
  `);

  // 2. Set default window size
  api.window.setSize(240, 180);

  // 3. Restore persisted state
  let count = api.storage.get('count') || 0;

  // 4. Render UI inside api.container
  const container = api.container;
  container.innerHTML = `
    <div class="counter-card">
      <div class="counter-display" id="count-val">${count}</div>
      <div class="counter-controls">
        <button class="counter-btn" id="dec-btn">-</button>
        <button class="counter-btn" id="inc-btn">+</button>
        <button class="counter-btn" id="reset-btn">↺</button>
      </div>
    </div>
  `;

  const display = container.querySelector('#count-val');

  function updateCount(val) {
    count = val;
    display.textContent = count;
    api.storage.set('count', count);
  }

  // 5. Attach event listeners
  container.querySelector('#inc-btn').addEventListener('click', () => updateCount(count + 1));
  container.querySelector('#dec-btn').addEventListener('click', () => updateCount(count - 1));
  container.querySelector('#reset-btn').addEventListener('click', () => updateCount(0));

  // 6. Listen to global events
  api.bus.on('board:restarted', () => {
    api.notify('Counter ready!', 'info');
  });
}

export function teardown() {
  // Optional: The core handles 100% of event, timer, and DOM cleanup automatically!
}
```

## Step 2: Testing Your Plugin Locally

1. Serve Blank Board locally:
   ```bash
   npx serve Another/
   ```
2. Open `http://localhost:3000` in your browser.
3. Right-click on the board to open the **Plugin Manager**.
4. Click **Install via URL** and input your local URL or relative path:
   ```
   ./plugins/counter-widget.js
   ```
5. Your widget will instantly appear on the canvas!

---

## Step 3: Publishing to the Community Store

1. Push your plugin file to your public GitHub repository.
2. Fork the [`blank-board-plugins`](https://github.com/dheeraz101/Empty_Plugins) repository.
3. Add your plugin entry to `plugins.json`:
   ```json
   {
     "id": "counter-widget",
     "name": "Quick Counter",
     "url": "https://raw.githubusercontent.com/username/my-plugins/main/counter-widget.js",
     "author": "Your Name",
     "description": "A lightweight, stylish counter widget with persistent storage.",
     "icon": "🔢",
     "date": "2026-08-17"
   }
   ```
4. Open a Pull Request! Once merged, all Blank Board users can install your plugin with 1 click from the Discovery store.
