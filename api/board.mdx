## Overview

In Blank Board, the canvas is an open, transformable workspace (`api.boardEl`), and every plugin renders inside a secure, managed container (`api.container`).

<Warning>
  **Strict Rule:** Plugins MUST render their UI inside `api.container`. Never append directly to `api.boardEl` or `document.body` unless you are building a full-board theme or fullscreen canvas mode.
</Warning>

---

## `api.container` (Primary UI Root)

Every plugin automatically receives an isolated, managed container element.

```javascript
export function setup(api) {
  const container = api.container;

  // Build your UI inside your container
  container.innerHTML = `
    <div class="my-widget-card">
      <h2>My Widget</h2>
      <button id="action-btn">Click Me</button>
    </div>
  `;

  container.querySelector('#action-btn').addEventListener('click', () => {
    api.notify('Action executed!', 'success');
  });
}
```

### Container Guarantees
- **Auto-Positioned & Sized**: Automatically placed on the canvas with smooth CSS transitions.
- **Draggable & Resizable**: Drag handle on the header/body, resize handle at the bottom-right corner.
- **Focus & Z-Index Elevation**: Clicking a container automatically brings it to the top of the window stack (`.bb-focused`).
- **Scoped CSS Protection**: CSS injected via `api.injectCSS()` is automatically scoped to your container `[data-plugin-id="..."]`.
- **Zero-Leak Cleanup**: When unloaded, the container and all internal elements are destroyed automatically by the core.

## `api.window` (Window & Canvas Controls)

Plugins can programmatically control their window position, size, and focus:

```javascript
export function setup(api) {
  // Bring window to front
  api.window.bringToFront();

  // Set position on board (x, y in pixels)
  api.window.setPosition(100, 150);

  // Set dimensions
  api.window.setSize(400, 300);

  // Get current bounding rectangle
  const rect = api.window.getBounds();
  console.log('Window dimensions:', rect.width, rect.height);
}
```

## `api.boardEl` (Canvas Root)

`api.boardEl` is the root `#board` DOM element spanning `100vw × 100vh`. It is typically used for reading viewport dimensions, attaching canvas listeners, or applying board-wide theme attributes.

### Canvas Modes & Grid Styling

The board supports multiple built-in canvas background patterns:

```javascript
// Switch grid pattern
api.boardEl.dataset.grid = 'dots'; // 'dots' | 'none' | default lines

// Switch canvas mode
api.boardEl.dataset.mode = 'fullscreen-app'; // Takes over full viewport
```

### Board CSS Custom Variables

Board themes can customize CSS variables on `:root` or `#board`:

| CSS Variable | Default | Purpose |
|---|---|---|
| `--board-bg` | `#f8f9fa` | Background color of the canvas |
| `--grid-line` | `#e2e4e9` | Grid pattern color |
| `--grid-size` | `40px` | Spacing of the grid lines/dots |
| `--accent-color` | `#7c6fff` | System primary accent |
| `--window-bg` | `#ffffff` | Plugin container background color |
| `--window-radius` | `14px` | Plugin container corner radius |

## Complete Plugin Skeleton

```javascript
export const meta = {
  id: 'my-custom-tool',
  name: 'Custom Tool',
  version: '1.0.0'
};

export function setup(api) {
  // 1. Inject scoped styles
  api.injectCSS(`
    .my-box {
      padding: 16px;
      display: flex;
      flex-direction: column;
      gap: 10px;
    }
  `);

  // 2. Render inside managed container
  const container = api.container;
  container.innerHTML = `
    <div class="my-box">
      <h3>${meta.name}</h3>
      <p>Loaded successfully!</p>
    </div>
  `;

  // 3. Optional: Set initial window size
  api.window.setSize(300, 200);
}

export function teardown() {
  // Core automatically cleans up containers, styles, bus listeners, and timers!
}
```
