## Overview

In traditional web development, forgetting to call `clearInterval()` or `cancelAnimationFrame()` in `teardown()` results in zombie background timers that waste CPU cycles and leak memory.

On Blank Board v5.0, `api.setInterval`, `api.setTimeout`, and `api.requestAnimationFrame` are **automatically tracked and disposed of** whenever your plugin is unloaded, reloaded, or deleted.

---

## `api.setInterval(callback, ms)`

Creates a recurring timer that fires every `ms` milliseconds. Automatically cleared on teardown.

```javascript
export function setup(api) {
  let seconds = 0;
  
  // Timer runs every second and automatically stops when plugin unloads
  api.setInterval(() => {
    seconds++;
    console.log('Elapsed seconds:', seconds);
  }, 1000);
}
```

---

## `api.setTimeout(callback, ms)`

Sets a one-shot timer that fires after `ms` milliseconds. Automatically cancelled if the plugin unloads before execution.

```javascript
export function setup(api) {
  api.setTimeout(() => {
    api.notify('3 seconds passed since startup!', 'info');
  }, 3000);
}
```

---

## `api.requestAnimationFrame(callback)`

Requests a frame render callback on the browser's animation loop. Ideal for games, physics, and canvas animations.

```javascript
export function setup(api) {
  const canvas = document.createElement('canvas');
  const ctx = canvas.getContext('2d');
  api.container.appendChild(canvas);

  let x = 0;

  function loop() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.fillRect(x % canvas.width, 50, 20, 20);
    x += 2;

    // Automatically stops when plugin is unmounted
    api.requestAnimationFrame(loop);
  }

  api.requestAnimationFrame(loop);
}
```
