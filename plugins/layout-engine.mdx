## Overview

The **Layout Engine** (`layout.js`) transforms the freeform floating board into structured columns, sidebars, and tiling grids.

---

## Features

- **Zone Docking**: Drag any plugin container into a highlighted zone to dock it.
- **Resizable Columns**: Drag column divider bars horizontally to resize layout zones smoothly.
- **Layout Presets**: Quick presets including 2-Column, 3-Column, Sidebar Left, and Split Screen.
- **Drag-to-Undock**: Dragging a docked plugin automatically undocks it back to freeform floating mode.

---

## Usage

1. Install **Layout Engine** from the Community Discovery store.
2. Select a column layout preset from the top toolbar or layout menu.
3. Drag widgets and plugins into layout zones. They will automatically expand to 100% width and height of the zone.
