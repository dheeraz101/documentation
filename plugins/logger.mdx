## Overview

The **Logger** is a system plugin that records board lifecycle events, plugin installation and update operations, error reports, and storage changes.

---

## Features

- **Live Event Stream**: Captures lifecycle events like `pm:install-success`, `plugin:loaded`, `plugin:error`, and `service:registered`.
- **Diagnostic Viewer**: Injects a **Logs** button into the Plugin Manager header for reviewing timestamps, event payloads, and stack traces.
- **Dark/Light Theme**: Theme-aware log inspector overlay with search and clear history capabilities.

---

## Accessing Logs

1. Open the **Plugin Manager**.
2. Click the **Logs** button in the top action area.
3. Review recorded events, inspect payloads, or export logs for debugging.
