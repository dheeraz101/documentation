## Overview

Blank Board provides a **hybrid storage engine**:
1. **`api.storage` (LocalStorage)**: Synchronous, ultra-fast key-value persistence for small settings, preferences, and toggle states.
2. **`api.storage.db` (IndexedDB)**: Asynchronous, quota-free storage for large binary blobs, audio tracks, canvas images, documents, and game states.

---

## 1. Fast Key-Value Storage (`api.storage`)

In v5.0, `api.storage.get()` and `api.storage.set()` are automatically scoped to your plugin ID:

```javascript
export function setup(api) {
  // Store a preference
  api.storage.set('theme', 'dark');

  // Read a preference (returns null if key does not exist)
  const currentTheme = api.storage.get('theme') || 'system';
  
  // Remove a key
  api.storage.remove('theme');
}
```

### Storage Change Events
Whenever a storage key is modified, the event bus emits a `storage:change` event:

```javascript
api.bus.on('storage:change', ({ key, value, oldValue, pluginId }) => {
  console.log(`Key ${key} changed from`, oldValue, 'to', value);
});
```

## 2. Large Data & Blob Storage (`api.storage.db`)

When building canvas drawing tools, audio recorders, music players, or games with large save files, use `api.storage.db` to bypass the 5MB `localStorage` limit:

```javascript
export function setup(api) {
  const canvas = document.createElement('canvas');

  // Save canvas image blob / base64 to IndexedDB
  async function saveDrawing() {
    const dataUrl = canvas.toDataURL();
    await api.storage.db.set('saved-canvas', dataUrl);
    api.notify('Canvas saved to IndexedDB!', 'success');
  }

  // Restore drawing from IndexedDB
  async function loadDrawing() {
    const dataUrl = await api.storage.db.get('saved-canvas');
    if (dataUrl) {
      const img = new Image();
      img.onload = () => canvas.getContext('2d').drawImage(img, 0, 0);
      img.src = dataUrl;
    }
  }
}
```

### `api.storage.db` Methods

| Method | Description |
|---|---|
| `api.storage.db.get(key)` | Asynchronously retrieves stored value or `null` |
| `api.storage.db.set(key, value)` | Asynchronously stores any JSON object, string, array, or binary Blob |
| `api.storage.db.delete(key)` | Deletes the specified key from IndexedDB |
